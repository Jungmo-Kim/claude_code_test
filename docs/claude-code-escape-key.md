# Claude Code에서 Esc 키 활용하기

`Esc` 키로 Claude의 작업을 멈추고, 입력을 지우고, 대화를 이전 시점으로 되돌릴 수 있습니다. 세션을 끝내지 않고 방향만 바로잡을 때 가장 자주 쓰는 키입니다.

> `Ctrl+C`는 세션을 종료할 수 있지만 `Esc`는 진행 중인 작업만 멈춥니다. Claude가 엉뚱한 방향으로 갈 때는 `Esc`로 끊고 바로 새 지시를 내리세요.

## 작업 중단 (Esc 한 번)

Claude가 응답을 쓰거나 도구를 실행하는 중에 `Esc`를 누르면 그 자리에서 멈춥니다.

1. 작업 중에 `Esc`를 누릅니다.
2. 입력창이 다시 활성화됩니다. 그때까지의 대화 맥락은 그대로 남아 있습니다.
3. "그 파일 말고 `README.md`를 고쳐줘"처럼 바로 방향을 바꾸는 지시를 입력합니다.

> 이미 실행된 파일 수정은 멈춘다고 되돌아가지 않습니다. 되돌리려면 아래 rewind를 사용하세요.

## 입력 지우기와 되돌리기 (Esc 두 번)

`Esc`를 빠르게 두 번 누르면 입력창 상태에 따라 동작이 달라집니다.

| 입력창 상태 | 동작 |
| --- | --- |
| 글자가 있음 | 입력한 내용을 모두 지웁니다. |
| 비어 있음 | rewind 화면을 엽니다. |

rewind 화면에서 이전 시점으로 돌아가는 방법은 다음과 같습니다.

1. 입력창을 비운 상태에서 `Esc`를 두 번 누릅니다.
2. 이전에 보낸 메시지 목록에서 돌아갈 지점을 고릅니다.
3. 대화만, 코드만, 또는 둘 다 되돌릴지 선택합니다.
4. 되돌린 지점부터 다른 지시로 다시 시작합니다.

## 대화상자·메뉴 닫기

- 권한 요청 창에서 `Esc`를 누르면 해당 도구 실행을 거절합니다.
- `/` 커맨드 목록, `@` 파일 자동완성 같은 메뉴가 열려 있으면 닫습니다.

## vim 모드

`/vim`으로 vim 모드를 켜면 `Esc`는 vim과 같이 INSERT 모드에서 NORMAL 모드로 전환하는 키가 됩니다.

## 정리

| 상황 | 키 | 효과 |
| --- | --- | --- |
| Claude가 작업 중 | `Esc` | 작업 중단, 맥락 유지 |
| 권한 요청·메뉴가 열림 | `Esc` | 거절하거나 닫기 |
| 입력창에 글자가 있음 | `Esc` `Esc` | 입력 지우기 |
| 입력창이 비어 있음 | `Esc` `Esc` | rewind로 이전 시점 되돌리기 |
| vim 모드 | `Esc` | NORMAL 모드로 전환 |

> 단축키를 바꾸고 싶다면 `~/.claude/keybindings.json`에서 재지정할 수 있습니다.
