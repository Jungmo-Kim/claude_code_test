# Claude Code에서 bash 명령어 사용하기

Claude Code에서 bash 명령어를 쓰는 방법은 두 가지입니다. `!`를 붙여 직접 실행하거나, 자연어로 요청해 Claude가 `Bash` 도구로 실행하게 합니다. 자주 쓰는 명령은 미리 허용해 두면 승인을 묻지 않고 실행됩니다.

## `!`로 직접 실행 (bash 모드)

프롬프트 맨 앞에 `!`를 붙이면 Claude를 거치지 않고 셸에서 바로 실행됩니다.

```
! git status
! ls -la docs/
```

- Claude가 해석하지 않으므로 빠르고 토큰도 거의 쓰지 않습니다.
- 실행 결과는 대화 맥락에 추가됩니다. 그래서 "방금 나온 에러 고쳐줘"처럼 결과를 두고 바로 이어서 요청할 수 있습니다.

> 이 기능은 터미널 CLI 기준입니다. VS Code 확장에서는 동작이 다를 수 있으니, 안 되면 통합 터미널에서 `claude`를 실행해 쓰세요.

## Claude에게 실행 요청 (`Bash` 도구)

자연어로 요청하면 Claude가 `Bash` 도구로 명령을 실행하고 결과를 해석합니다.

```
테스트 돌려보고 실패한 거 원인 알려줘
최근 커밋 5개 보여줘
```

1. Claude가 실행할 명령을 정합니다.
2. 허용 규칙에 없는 명령이면 권한 요청 창이 뜹니다. 이번만 허용할지, 앞으로 계속 허용할지 고릅니다.
3. 실행 결과를 Claude가 읽고 다음 작업을 이어갑니다.

> 작업 디렉터리(`cd`)는 다음 호출에도 유지되지만, `export`로 설정한 환경 변수 같은 셸 상태는 유지되지 않습니다.

## 자주 쓰는 명령 미리 허용하기

설정 파일의 `permissions`에 규칙을 넣어 두면 승인 없이 실행되거나 아예 막힙니다.

```json
{
  "permissions": {
    "allow": ["Bash(git status)", "Bash(git diff:*)", "Bash(npm run test:*)"],
    "deny": ["Bash(rm -rf:*)"]
  }
}
```

| 위치 | 적용 범위 |
| --- | --- |
| `~/.claude/settings.json` | 모든 프로젝트 (전역) |
| `.claude/settings.json` | 현재 프로젝트 (저장소에 커밋해 공유) |
| `.claude/settings.local.json` | 현재 프로젝트 (나만 사용, 커밋하지 않음) |

`/permissions` 명령으로 화면에서 규칙을 확인하고 고칠 수도 있습니다.

## 오래 걸리는 명령 다루기

- 개발 서버처럼 끝나지 않는 명령은 "백그라운드로 실행해줘"라고 요청합니다.
- 이미 실행 중인 명령은 `Ctrl+B`로 백그라운드로 보낼 수 있습니다.
- 기본 타임아웃은 2분이고 최대 10분까지 늘릴 수 있습니다. 환경 변수 `BASH_DEFAULT_TIMEOUT_MS`, `BASH_MAX_TIMEOUT_MS`로 조정합니다.

## 정리

| 방법 | 사용 예 | 특징 |
| --- | --- | --- |
| `!` 접두사 | `! git log --oneline` | 직접 실행하고 결과만 맥락에 추가 |
| 자연어 요청 | "빌드 돌려줘" | Claude가 실행하고 결과를 해석 |
| `permissions.allow` | `Bash(git diff:*)` | 승인 없이 실행 |
| `permissions.deny` | `Bash(rm -rf:*)` | 실행 차단 |
